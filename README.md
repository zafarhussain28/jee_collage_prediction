# JEE College Predictor

A Streamlit web application for exploring college programs against a JEE rank. It uses the trained CatBoost model included in this repository together with historical JoSAA counselling records. It is an informational tool: results are estimates, not admission probabilities, official eligibility decisions, or guarantees of admission.

## Quick Start

Use Python 3.12. From the project root, create an environment, install dependencies, and start Streamlit:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Streamlit prints a local URL (usually `http://localhost:8501`) where the app can be opened in a browser. The model artifact (`COLLEGE_MODEL (1).pkl`) and dataset (`JoSAA_2019_2024_CLEAN_FINAL.csv`) must remain beside `app.py`; both are included in this repository. The app loads them using project-relative paths and reports an error if either is missing or invalid.

## How to Use

Set the options in the sidebar, then select **Find matching programs**:

1. Enter your whole-number JEE rank, not your percentile.
2. Select a historical year. The available counselling rounds update to match that year.
3. Choose a round, quota, seat type, and JoSAA seat gender category.
4. Optionally select institutes and programs to narrow the results. Leave either preference blank to include all available choices.

The gender choices come from the supplied data: `Gender-Neutral` and `Female-only`. Male applicants should choose `Gender-Neutral`; the dataset and model do not have a separate `Male` category. The app does not ask for home state because the data has no state field or documented mapping to home-state quota.

## Understanding Results

The model estimates a closing rank for each matching historical program row. A row is marked as a model-estimated match when its estimated closing rank is greater than or equal to the entered JEE rank. For example, an estimated closing rank of 12,000 is a rank comparison match for an entered rank of 10,000. This comparison is not an admission decision.

The results table shows the institute, program, model-estimated closing rank, the historical opening and closing ranks, year, round, quota, seat type, and gender category. The historical rank columns are the recorded values from the selected counselling year and round; they are not generated by the model. If matching records exist but none meet the model comparison, the app shows up to 20 closest estimates for comparison. If no rows match the selected filters, it explains that no historical records were found.

## Model and prediction behavior

The serialized artifact contains a `CatBoostRegressor`, its feature-column list, and categorical feature indices. It predicts a **closing rank**; it does not predict a college category or admission probability. The application validates that the artifact's feature schema matches the training notebook before inference.

The model input columns, in order, are `institute`, `academic_program_name`, `quota`, `seat_type`, `gender`, `year_norm`, `round_norm`, `institute_tier`, `branch_demand`, and `home_advantage`. The first five are categorical. The remaining fields use the feature engineering in `actual_code.ipynb`: institute/program tiers, HS-quota indicator, year normalized over the complete dataset, and round divided by the complete dataset's maximum round.

For a selected year, round, quota, seat type, and gender category, the app filters actual CSV rows and sends those rows' engineered features to the existing model. Institute and program preferences narrow those same data-backed rows. The app does not retrain the model, invent cutoff records, or calculate admission probabilities.

The original notebook uses a random train/test split. The repository does not include saved evaluation metrics or validation against a later counselling year. Historical cutoffs and model estimates should be used for exploration only; actual counselling outcomes depend on current-year rules, seat availability, and applicant choices.

## Data coverage

The repository CSV has 82,723 records and includes institute, academic program, quota, seat type, gender category, opening rank, closing rank, year, and round. Although its filename says `2019_2024`, the supplied records cover **2021–2024** only. Available rounds are 1 and 6 for 2021–2023, and 1 and 5 for 2024. Interface categories and choices are derived from the CSV.

The project identifies the records as JoSAA data but does not document an external source URL or provenance. The app does not fetch current counselling data or retrain the model.

## Tests

Run the automated tests from the project root with:

```bash
python -m pytest -q tests
```

Tests cover model loading and schema validation, inference with the included artifact and data, invalid ranks and filters, missing model artifacts, empty historical matches, and Streamlit rendering and submission.

## Streamlit Community Cloud

Create a Streamlit Community Cloud app from this repository and set `app.py` as the entry point. Keep `requirements.txt`, `COLLEGE_MODEL (1).pkl`, and `JoSAA_2019_2024_CLEAN_FINAL.csv` in the deployed repository. Python 3.12 is recommended. The model and CSV are approximately 7.5 MB and 13 MB, respectively. No secrets or external services are required.
